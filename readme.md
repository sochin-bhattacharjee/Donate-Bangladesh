# Donate Bangladesh

## Live Link : https://sochin-bhattacharjee.github.io/Donate-Bangladesh/

Donate Bangladesh is a platform that allows users to donate for various causes, such as flood relief and support for the injured in the Quota Movement. It provides a user-friendly interface to view donation options, donate money, and track donation history.

## Tech Stack
- **HTML**: Structure of the website.
- **CSS**: Styling the components.
- **Tailwind CSS**: Utility-first CSS framework.
- **DaisyUI**: Plugin for Tailwind CSS for additional UI components.

## Features
- **Donation Cards**: Multiple donation options for different causes.
- **Real-Time Donation Updates**: Users can add donations and track changes to the total donation amount.
- **History Tracking**: View a history of all donations made, including the amount and the cause.
- **Modal Confirmation**: After a donation, a modal will confirm the success of the donation.

## Dependencies
- **Tailwind CSS**: For styling and responsive design.
- **DaisyUI**: For UI components.
